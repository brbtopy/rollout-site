# rollout-site

Public web pages for the **Roll Out** app (a roadside-towing marketplace), served
via GitHub Pages at **https://brbtopy.github.io/rollout-site/**.

This repo exists so the app has publicly reachable URLs that the Google Play
listing and Data safety form require — a Privacy Policy and an account/data
deletion page that work without installing the app. The app's source lives in a
separate (private) repository; only these public pages live here.

| Page | URL |
| --- | --- |
| Landing | `/` (`index.html`) |
| Privacy Policy | `/privacy.html` |
| Terms of Service | `/terms.html` |
| Account & data deletion | `/account-deletion.html` |

Contact: **devs.rollout@gmail.com**

> before they are relied on. Keep them in sync with the in-app Legal screens.
